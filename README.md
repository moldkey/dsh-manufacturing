<p align="center"><strong>dsh-manufacturing — 制造工艺套装</strong></p>

按材料/数量/尺寸/精度推荐工艺，并给出 14 个制造工具的安装入口。

## 安装

    dsh plugin --profile web add github:moldkey/dsh-manufacturing

## 工具

- `manufacturing_process_select`：工艺选择
- `manufacturing_tool_map`：工具地图

## 套装包含

sheetmetal / injection-molding / cnc / die-casting / stamping / welding / mold / dfm / bom / qc / tolerance / material / hs-code / packing-list

更多工具：https://deepseekbase.com/zh/tools/
